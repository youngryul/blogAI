# 커넥트노트 수집기 (크롬 확장 프로그램)

네이버에 **로그인한 내 브라우저**에서 블로그 통계·애드포스트·브랜드 커넥트 화면을 열면,
그 화면이 받아온 숫자(일별 방문자 수, 수익)를 읽어 커넥트노트 대시보드로 보냅니다.

- 네이버 아이디·비밀번호를 저장하거나 대신 로그인하지 않습니다.
- 네이버에 요청을 새로 보내지 않고, 내가 연 화면이 이미 받은 응답만 읽습니다.
- 글은 블로그 글쓰기 화면에 채워 두기만 하고, 발행 버튼은 직접 누릅니다.

## 설치

1. Supabase SQL Editor 에서 `supabase/migrations/20261109000300_blog_metrics.sql` 실행
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
4. 커넥트노트 **설정 → 크롬 확장 프로그램 연결**에서 **연결 코드 만들기** → 코드 복사
5. 크롬 툴바의 커넥트노트 아이콘 → 앱 주소와 연결 코드 입력 → **저장 후 연결 확인**

## 사용

네이버에 로그인한 상태로 아래 화면을 엽니다. 날짜 범위를 바꾸면 그 기간도 함께 저장됩니다.

| 화면 | 저장되는 값 |
|---|---|
| 블로그 관리 → 통계 (admin.blog.naver.com) | 일별 방문자 수 |
| 애드포스트 수익 리포트 (adpost.naver.com) | 일별 애드포스트 수익 |
| 브랜드 커넥트 수익 화면 (brandconnect.naver.com) | 일별 커넥트 수익 |
| 브랜드 커넥트 → 쇼핑 커넥트 → 상품 찾기 (인기·추천·검색 목록) | 상품명·가격·수수료율·이미지·순위 |
| 브랜드 커넥트에서 **링크 발급**을 누른 직후 | 발급된 쇼핑 커넥트 링크 |

## 새 콘텐츠에서 바로 고르기

> 먼저 Supabase SQL Editor 에서 `supabase/migrations/20261109000400_connect_products.sql` 을 실행하세요.

1. 브랜드 커넥트의 상품 찾기 화면(인기 순위·추천 탭 등)을 한 번 열어 둡니다.
2. 커넥트노트 **새 콘텐츠**의 **브랜드 커넥트에서 고르기**에서 상품을 고릅니다. 상품명·가격·이미지가 채워집니다.
3. 링크가 없으면 **브랜드 커넥트에서 링크 발급** → 열린 화면에서 (상품명이 복사돼 있으니 검색 후) **링크 발급**을 누릅니다.
4. 확장 프로그램이 발급 결과를 읽어 보내면, 새 콘텐츠 화면의 쇼핑 커넥트 URL 이 자동으로 채워집니다.

### 블로그 자동 작성 (0.5.0~)

> 먼저 Supabase SQL Editor 에서 `supabase/migrations/20261109000500_record_published_post.sql` 을 실행하세요.
> 설정에서 네이버 블로그 아이디를 연결해 두면 내 블로그 글쓰기 화면으로 바로 열립니다.

콘텐츠 **미리보기 → 블로그에 자동 작성**을 누르면:

1. 네이버 블로그 글쓰기 화면을 새 탭으로 엽니다(확인하실 수 있게 보이는 탭).
2. `blog-writer.js` 가 처음 뜨는 팝업(작성 중인 글·도움말)을 닫고, 제목 → 본문 → 사진 순서로 **붙여넣기**합니다. 사진은 파일로 붙여넣어 에디터가 직접 업로드합니다. 해시태그는 본문 끝에 들어갑니다.
3. **발행 버튼은 누르지 않습니다.** 내용을 확인하고 직접 발행하세요.
4. 발행 후 글 보기 화면으로 이동하면 그 주소를 커넥트노트에 **발행 완료**로 자동 기록합니다.

- 에디터 칸은 클래스 이름(`se-*`)으로 찾습니다. 제목·본문이 안 채워지면 글쓰기 화면의 제목 칸·본문 칸 HTML(검사 → Copy outerHTML)을 전달해 주세요. `blog-writer.js` 상단 `SELECTORS` 를 맞춰 고칩니다.
- 사진이 일부 안 들어가면 알림이 뜹니다. 미리보기의 이미지 다운로드로 받아 직접 올려 주세요.

### 링크 자동 발급 (0.4.0~)

새 콘텐츠에서 링크가 없는 상품을 고르면 확장 프로그램이 **자동으로 발급**합니다(실패하면 '링크 자동 발급' 버튼으로 다시 시도).

1. 상품을 봤던 브랜드 커넥트 화면을 최소화된 창으로 엽니다.
2. `automate.js` 가 화면에서 상품명을 찾고, 없으면 검색창에 상품명을 넣어 검색합니다.
3. 그 상품 카드의 **링크 발급** 버튼을 누르고, 확인 팝업이 뜨면 한 번 더 누릅니다.
4. 새로 나타난 `naver.me` 링크(또는 발급 응답)를 읽어 저장하고 창을 닫습니다 → 앱의 쇼핑 커넥트 URL 이 채워집니다.

- 내 크롬·내 네이버 로그인으로, 상품 하나씩만 발급합니다(동시에 여러 개 발급하지 않음).
- 버튼은 글자(`링크 발급` 등)로 찾습니다. 화면 구조가 달라 실패하면, 상품 카드와 발급 후 팝업의 HTML(검사 → Copy outerHTML)을 전달해 주세요. `automate.js` 상단 정규식을 맞춰 고칩니다.
- 배포 주소에서 쓰려면 팝업에 그 앱 주소를 저장해야 합니다(그 주소에 앱 연결 스크립트를 등록).

### 하루 1번 자동 갱신

상품 찾기 화면을 **한 번만** 직접 열어 두면, 확장 프로그램이 그 주소(최근 3개)를 기억했다가 하루 1번 정도 알아서 다시 엽니다.

- 크롬이 켜져 있으면 1시간마다 확인하고, 커넥트노트 앱에 들어올 때도 확인합니다. 마지막 갱신 후 **20시간**이 지났을 때만 실제로 갱신합니다.
- 최소화된 창으로 화면을 열고 약 10초 뒤 닫습니다. 화면이 스스로 받아오는 응답을 평소처럼 읽을 뿐, 네이버에 요청을 직접 만들지 않습니다.
- 네이버 로그인이 풀려 있으면 상품을 못 읽습니다. 팝업에 안내가 뜨면 로그인한 뒤 **지금 갱신**을 누르세요.
- 팝업의 체크박스로 끌 수 있습니다.

링크 발급은 브랜드 커넥트 화면에서 직접 누르는 방식입니다. 확장 프로그램이 대신 발급 요청을 보내지 않습니다.

## 숫자가 안 들어올 때

네이버 내부 응답 형식은 공개되어 있지 않아 필드 이름을 추측해서 읽습니다.
팝업의 **최근 수집 데이터 복사**를 눌러 나온 내용을 전달해 주시면 `extract.js`(지표)·`connect.js`(상품·링크) 를 맞춰 고칩니다.
복사한 내용의 `products`·`links` 값이 0이면 그 응답에서 상품이나 링크를 찾지 못한 것입니다.
확장 프로그램을 고친 뒤에는 `chrome://extensions` 에서 새로고침 버튼을 눌러 주세요.
